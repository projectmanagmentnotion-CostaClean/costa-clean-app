# Workflow

Lee `docs/COSTA_CLEAN_BRAND_SYSTEM.md`, hashes, dimensiones, variantes y consumidores. Comprueba que cada uso local tenga un nombre canónico y que no existan hotlinks o logos inventados.

# Boundaries

No descargues assets externos, no redibujes el logo oficial y no sustituyas colores semánticos V3 sin evidencia aprobada.

# Output

Entrega inventario, procedencia, contraste, usos, drift y acciones.
