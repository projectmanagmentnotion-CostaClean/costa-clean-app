# Workflow

Normaliza síntoma, reproduce, reduce, formula hipótesis, confirma causa y añade regresión. En barridos registra cada superficie y no cierres por el primer hallazgo.

# Boundaries

No presentes hipótesis como confirmadas, no uses datos reales, no debilites tests y no despliegues.

# Output

Entrega reproducción, evidencia, causa clasificada, fix mínimo, regresión, side effects y límites.
