# Workflow

Compara componentes, CSS y tests con la constitución. Busca valores arbitrarios, Unicode-as-icon, overflow, targets menores de 44px, safe-area incumplida y excepciones no documentadas.

# Boundaries

No rebajes la regla para obtener verde, no edites en gate independiente y no sustituyas tokens semánticos por primitivas de marca.

# Output

Entrega cobertura de tokens, drift, legacy markers, excepciones y severidad reproducible.
