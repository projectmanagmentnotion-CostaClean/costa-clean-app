# Workflow

Aplica la rúbrica de jerarquía, contraste, teclado, foco, targets, reduced motion, safe areas, responsive y estados. Verifica que las acciones sean comprensibles sin hover.

# Boundaries

Preserva contratos y rutas; no inventes diseño si falta evidencia Stitch y no cierres un PASS sin prueba.

# Output

Entrega superficie, criterio, evidencia, hallazgo y recomendación compatible con V3.
