# Workflow

Reconstruye base/head, compara diff con objetivo, revisa contratos, UX, responsive, accesibilidad, rendimiento, marca, secretos, docs y validaciones. Un check ausente queda como no ejecutado.

# Boundaries

No edites, no apruebes suposiciones, no rebajes prioridad y no fusiones ni despliegues.

# Output

Entrega hallazgos P0–P3, checks revisados, limitaciones y un veredicto independiente.
