# Workflow

Valida registry, tipos soportados, unknown/null, WebP, procedencia local, alt text, tamaño y consumo en list/workspace. La media siempre es secundaria a identidad, dirección y estado.

# Boundaries

No uses fotos de clientes, scraping, hotlinks ni media como fuente de verdad. No modifiques datos de inmuebles.

# Output

Entrega mapping, fallback, assets, integración, accesibilidad, no-hotlinks y tests.
