# Workflow

Para cada journey verifica entrada, primera decisión, acción primaria, éxito, error, cancelación, permiso, duplicado, persistencia, back y deep link. Protege la densidad mobile.

# Boundaries

No inventes APIs, source of truth, tracking ni estados financieros. No cambies contratos remotos durante esta skill.

# Output

Entrega un mapa de journeys y gaps de estado con evidencia y riesgo de pérdida de datos.
