# Workflow

Inspecciona primero tokens y referencias aprobadas; después revisa cada superficie y estado en sus anchors. Clasifica cada desviación con archivo, línea, captura o criterio faltante.

# Boundaries

No inventes sistema visual, colores, iconos ni layouts. No edites durante una revisión independiente y no toques producción.

# Output

Devuelve `PASS`, `PARTIAL`, `FAIL` o `WAITING_FOR_STITCH`, con jerarquía, densidad, contraste, estados y acciones recomendadas.
