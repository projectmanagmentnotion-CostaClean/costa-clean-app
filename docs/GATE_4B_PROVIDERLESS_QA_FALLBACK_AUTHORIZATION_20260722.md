## Decision

The Cloudflare Turnstile path remains the preferred future production architecture, but it is no longer a blocking prerequisite for Gate 4B QA.

The owner authorizes Codex to complete Gate 4B in QA using a provider-independent defense-in-depth path built only on the existing Costa Clean repository and Supabase QA. This fallback exists because no authenticated Cloudflare/provider setup is currently available to the continuation runner.

## Authorized QA architecture

`QA quiz frontend -> strict client contract + honeypot/minimum-interaction metadata -> public Supabase Edge Function -> strict server validation -> HMAC pseudonymous throttling -> private transactional RPC -> minimal insert`

Authorized controls:

1. Strict request body size limit.
2. Exact field allowlist and rejection of unknown fields.
3. Field length, type and value bounds.
4. Server-side recalculation of the quiz result.
5. Honeypot field.
6. Minimum interaction duration and bounded client timestamp validation.
7. One-time request nonce or replay key generated by the frontend and consumed server-side.
8. HMAC pseudonymous network fingerprint using a private pepper.
9. Short cooldown and bounded attempt window.
10. Short retention for throttling/replay records.
11. Generic public errors without internal details.
12. Fixed `search_path` and private RPC.
13. No anonymous execution of the private RPC.
14. No public read access to quiz history or throttling records.
15. No raw IP, token, full payload or user-agent persistence/logging.

## Authorized implementation

Codex may:

- generate a cryptographically secure pepper locally;

- reactivate continuation and stop before Gate 4C.

## Stop conditions

Stop only when one of these is materially unavoidable:

- Supabase QA authentication is unavailable and requires interactive login/MFA;
- the QA project identity cannot be proven exactly;
- the migration or Edge Function would affect production or financial/fiscal behavior;
- the private pepper cannot be installed without exposing it;
- the disposable proof fails;
- QA cleanup cannot prove zero synthetic residue.

A missing Cloudflare session, Turnstile widget, DNS access or dedicated QA hostname is not a blocker under this fallback.
